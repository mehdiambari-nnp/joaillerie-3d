# Checklist de test sur iPhone 17 Pro Max (Safari et Chrome iOS)
- [ ] Ouvrir l'URL HTTPS (accepter le certificat) ; pas de défilement horizontal ; barre sûre respectée.
- [ ] ⤒ Ouvrir MAQUETTE_GEMV.fbx depuis Fichiers (24 pièces, FR 61, 6 zones).
- [ ] Toucher bague → zone sélectionnée ; double toucher → cadrage ; pincer/tourner fluide (≥ 30 ips).
- [ ] Appliquer émeraude (pierre centrale), or rose (chaton), platine (griffes) ; annuler/rétablir.
- [ ] Partager (lien + QR), Fiche récap, Photo.
- [ ] AR : Quick Look s'ouvre, bague à l'échelle réelle (≈ 26 × 30 × 20 mm), posée sur une table.
- [ ] Essayer : permission caméra, objectif principal, « Main détectée », bague sur l'annulaire, occlusion par le doigt,
      réglages Doigt / Taille / Champ de vision / Retourner, photo. Tester main gauche et droite, paume et dos.
- [ ] Chrome iOS : même parcours (WebKit) ; si caméra refusée : Réglages ▸ Chrome ▸ Caméra.
- [ ] Mémoire : pas de rechargement automatique de l'onglet après plusieurs changements de matière.
Noter tout écart et ajouter `?debug` pour la console.
